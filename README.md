# مشغل المجد

تطبيق ويب لحساب تكلفة وأرباح مشغل الدفايات (خامات، إنتاج، مبيعات، مرتبات، مصروفات).
بيتثبت على الموبايل زي أي تطبيق، وبيشتغل من غير نت بعد أول فتح.

## الرفع على GitHub Pages

1. ادخل github.com وأنشئ repository جديد (مثلاً `majd-workshop`) وخليه Public.
2. من داخل الـ repository اضغط Add file ثم Upload files، واسحب كل محتويات المجلد ده (index.html و manifest.webmanifest و sw.js ومجلد icons).
3. اضغط Commit changes.
4. من Settings ثم Pages، اختار Deploy from a branch، الفرع main والمجلد root، واضغط Save.
5. بعد دقيقة أو اتنين هيظهر الرابط: `https://اسم-المستخدم.github.io/majd-workshop/`

## التثبيت على الموبايل

- أندرويد (Chrome): افتح الرابط، اضغط قائمة النقط التلاتة ثم Install app أو Add to Home screen.
- آيفون (Safari): افتح الرابط، اضغط Share ثم Add to Home Screen.

## البيانات

- البيانات بتتحفظ على الموبايل اللي بتسجل عليه، ومش بتتزامن تلقائي بين الأجهزة.
- من تاب «الملخص» ممكن تصدّر نسخة احتياطية (ملف JSON) وتستوردها على موبايل تاني.
- مسح بيانات المتصفح أو حذف التطبيق بيمسح البيانات، فخد نسخة احتياطية بشكل دوري.

## تحديث التطبيق

لو عدّلت الملفات ورفعتها تاني، غيّر رقم النسخة في أول سطر من `sw.js` (`majd-v1` إلى `majd-v2`) عشان الموبايلات تاخد التحديث.
